Layer Diff

Visual diff for QGIS vector layers. Compare two versions of a layer and see what was added, removed, and modified — with geometry changes on the map and attribute changes field-by-field.

Quick start

  1. Open the plugin from the toolbar or the Vector menu.
  2. Pick Layer A (before) and Layer B (after).
  3. Optionally enable a key field for stable ID-based matching. If skipped, the plugin falls back to geometry-based matching using an R-tree spatial index.
  4. Click Compute Diff.
  5. Three new memory layers appear in the project: added (green), removed (red), modified (orange).
  6. Click any modified row in the table to flash + zoom to the feature and see a per-field old → new breakdown.
  7. Use Export HTML or Export CSV to save a report.

Matching strategies

Key-based matching

Match features by a unique identifier field (e.g. building_id). Fast and exact — O(n) — but requires a stable, unique key in both layers.

Geometry-based matching

Match features by spatial location. Uses a Shapely STRtree for O(n log n) performance. The optional tolerance parameter widens the search radius (in layer units).

CRS handling

If the two layers have different coordinate reference systems, Layer B is reprojected to Layer A's CRS before comparison, and a notification is shown.

Programmatic use

The core diff logic is pure Python (no QGIS imports) and lives in qgis_layer_diff/core/. It can be used from the QGIS Python console or a standalone script:

from qgis_layer_diff.core.differ import compute_diff
from qgis_layer_diff.core.models import FeatureRecord
from qgis_layer_diff.core.report import to_html, to_csv

result = compute_diff(records_a, records_b, key="id")
print(result.summary)  # {"added": 1, "removed": 0, "modified": 0, ...}
with open("report.html", "w") as f:
    f.write(to_html(result))
