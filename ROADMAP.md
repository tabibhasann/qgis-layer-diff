# Roadmap

## v0.2 (released)
- [x] Key-based and geometry-based feature matching
- [x] HTML and CSV diff reports
- [x] CRS warnings for mismatched layers
- [x] Detail view for individual feature diffs
- [x] qgis-plugin-ci integration

## v0.3
- Visual side-by-side map diff view
- Attribute-only diff mode
- Export diff to GeoJSON
- Support for raster layer diff

## v0.4
- Batch diff multiple layer pairs
- Configurable matching tolerance UI
- Diff statistics summary panel

## v1.0
- Stable plugin API
- Full QGIS Plugin Repo integration
- Comprehensive test coverage
- Internationalization support
