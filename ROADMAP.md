# Roadmap

## v0.2 (released)
- [x] Key-based and geometry-based feature matching
- [x] HTML and CSV diff reports
- [x] CRS warnings for mismatched layers
- [x] Detail view for individual feature diffs
- [x] qgis-plugin-ci integration

## v0.3 (release candidate)
- [x] Version metadata and release automation prepared for 0.3.0
- [x] Key and geometry matching, reports, CRS handling, and regression coverage
- [x] CHANGELOG updated with 0.3.0 section
- [x] README API section corrected to use actual parameter names
- [x] Documentation release-readiness sweep completed
- [ ] Build and manually verify the plugin ZIP inside the supported QGIS versions
- [ ] Publish to the official QGIS Plugin Repository
- [ ] Replace repository-install instructions only after the official listing resolves

## v0.4
- Visual side-by-side map diff view
- Attribute-only diff mode
- Export diff to GeoJSON
- Evaluate raster layer diff as a separate scope
- Batch diff multiple layer pairs
- Configurable matching tolerance UI
- Diff statistics summary panel

## v1.0
- Stable plugin API
- Full QGIS Plugin Repo integration
- Comprehensive test coverage
- Internationalization support
